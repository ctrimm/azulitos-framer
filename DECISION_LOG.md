# Decision Log — Azulitos

Every data-backed decision, with evidence and date. Revisit an entry when new evidence contradicts it.

- **D1 — Seamless-first, plus standalones (Cory, 2026-11-26).** The set leads with quarter-motif *padrão* tiles that repeat into panels — the behaviour that makes azulejos azulejos — plus a handful of standalone medallions. Evidence: the reference sets (Ornamental Glyphs, Decorative Tiles, both free, 24 vectors, same creator) are standalone-only; seamless panelling is the open lane and the authentic one.
- **D2 — 72 tiles (assistant's call under Cory's "prefer more", 2026-11-26).** 48 Padrão + 16 Medalhão + 8 Polícromo. Three times the reference sets' 24; generation is programmatic, so count is cheap, but QA and gallery work scale with it — 72 is generous without bloat. Porthole (paid) stays the bigger pack by delivered value (120 shapes + 360 files).
- **D3 — Cobalt on white with one Color variable; 8 polychrome (Cory, 2026-11-26).** Cobalt `#1E4FA3` shapes only (the white is the user's ground), all bound to a single Framer Color variable named **Azul** so the set recolors from one control. Polychrome group uses the fixed Lisbon palette (cobalt, yellow, green, manganese) as static fills — authentic panels are painted, not recolored.
- **D4 — Naming: AZL-01…72 + Portuguese motif names (Cory approved, 2026-11-26).** Follows Porthole's PRT pattern. Item names in Framer are `AZL-01 Estrela` style — searchable inside the set.
- **D5 — Public repo, free exports (Cory, 2026-11-26).** The set is free; the SVG/PNG exports ship free too, via this repo's releases, linked from the listing and Start Here. Fits the funnel role (D6) and costs nothing.
- **D6 — Funnel role (Cory, 2026-11-26).** Azulitos is the front door to the Ignite Bright Framer catalog. The Framer project's Start Here page carries a "More from Ignite Bright" section cross-referencing the other products (Porthole, Nocturne, Waymark live now; Wagesmith joins when reinstated). Note: vectors earn no referral commission — the payoff is audience and reputation, so the cross-references are the mechanism.
- **D7 — Name (checked 2026-11-26).** "Azulitos" — no Framer template, vector set, plugin, or component with that name found in a first-pass search (the formal collision check runs again in the build, per SUBMISSION_CHECKLIST). Fallbacks if taken: Azulejos (also clear in the first pass), Azulinhos, Padrão.
- **D8 — Generation method + QA gates (2026-11-26).** Code-generated geometry from a quarter-tile symmetry grammar (design the quarter, mirror to the full tile — edge continuity by construction), the Porthole method. QA gates: every tile rendered at 200px and 1000px; every Padrão/Polícromo tile also rendered in 2×2 and 4×4 panels with a seam check; contact sheets reviewed before the Framer build starts.
- **D9 — Original motifs only (2026-11-26).** Designs are generated from a motif grammar (stars, rosettes, quatrefoils, lace bands, sprigs) in the manner of the tradition. No historical panel is traced or copied — Framer's vectors best practices require original artwork, and a traced 17th-century panel would fail both the letter and the point.
- **D10 — Padrão families: mix-and-match seamless (agent, 2026-11-26).** The 48 Padrão tiles are 8 families of 6, one per corner motif (Estrela, Roseta, Quadrifólio, Sol, Flor, Cruz, Leque, Losango). Within a family every element that crosses the tile edge (corner radius, edge-midpoint motif, frame ring) is identical, so any family members can be mixed in one panel and still read as one cloth. Evidence: `scripts/qa.py` family-mix test, every pair of tiles in each family, worst edge mismatch ≤ 0.00013 mean |Δα| (`TILE_TEST.md`); mixed 4×4 panels in `qa/panels/mixed-*`. This is what makes the spec's "mixed-tile panel" money shot seamless rather than a patchwork.
- **D11 — How the Azul variable recolors (agent, 2026-11-26, from Framer probes in this build).** Every cobalt fill in the vector set is bound to the set's Color variable **Azul** (default `#1E4FA3`) — verified by reading the nodes back (`fill: {type: reference, id: Azul}`). In Framer, a vector-set variable surfaces as a per-instance **Azul** control on each inserted tile, initialised from the set default at insert time; changing the set default later does not repaint tiles already placed. One-control recolor across many placed tiles works by pointing their Azul controls at one project Color Style — probe: 3 instances bound to one style, style changed once, all 3 repainted. Start Here documents this. A true fresh-project test (paste the Vectors URL into a blank project) needs the set's share URL, which the Framer MCP does not expose; Cory runs it as part of the existing paste-test step.
- **D12 — Geometry representation (agent, 2026-11-26).** Framer `PathNode`s take one straight/cubic subpath each, so a tile is a list of filled polygons: shapes without holes are single paths; shapes with holes are a Boolean *subtract* of the outline and its holes, with the fill (and the Azul binding) on the Boolean. Curves are polylines with ≤ 0.12 px chord error at 1000 px (invisible at any display size) rather than fitted Béziers — simpler, exact, and checked by the geometry gate. Cost: 13–102 filled shapes per tile (avg ≈ 67); recorded per tile in `TILE_TEST.md`.
- **D13 — Framer project (agent, 2026-11-26).** No Azulitos project existed in Cory's workspace, so the build created one titled "Azulitos — Portuguese Tiles" (`8Olu9pRUODh1lsz4SeYC`). Nothing published.
- **D14 — Showcase uses renders, not live instances (agent, 2026-11-26).** After the bulk import the Framer MCP icon catalog for the Azulitos set froze at its first compiled state (AZL-01 only). Re-opening the project, renaming the set, re-toggling items, shrinking the set to 10 items, and creating a fresh set all failed to refresh it; any page holding set instances then failed to render in Framer's screenshot pipeline ("modules missing"). The vector-set module is rebuilt and saved on Framer's side, out of reach of the build tooling. So the Showcase shows panels and group sheets rendered from the same generated SVGs (`qa/panels/`, `qa/sheets/showcase-*.png`), and the page renders cleanly. Opening the project in the Framer editor should rebuild the set; live instances can then replace any render.
- **D15 — Cross-references removed for now (Cory, 2026-11-27).** The "More from Ignite Bright" section (Porthole, Nocturne, Waymark) is removed from the Framer project's Start Here page until further notice. This pauses the D6 funnel mechanism on Start Here. The same lines are removed from `MARKETPLACE_LISTING.md`; Cory updates the live listing.
