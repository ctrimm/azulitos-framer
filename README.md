# Azulitos — Portuguese Tiles for Framer

A **free** Framer vector set of little Portuguese tiles ("azulitos"), in the manner of traditional azulejos: cobalt-blue motifs on white, built to repeat into panels.

## Why this exists

Framer's vector shelf has standalone ornamental glyphs, but nothing that behaves like a real azulejo wall — where each tile carries a quarter of the design and the full rosette only appears when tiles meet. Azulitos is built seamless-first: most tiles are quarter-motif *padrão* designs that panel endlessly, with standalone medallions and a small polychrome Lisbon-palette group alongside. It's free because it's the front door: a funnel to the rest of the Ignite Bright Framer catalog (Porthole, Nocturne, Wagesmith, Waymark), cross-referenced on the set's Start Here page.

## What's inside (72 tiles)

- **AZL-01…48 — Padrão** (cobalt, seamless): quarter-motif pattern tiles that repeat into panels.
- **AZL-49…64 — Medalhão** (cobalt, standalone): complete medallion tiles for single use.
- **AZL-65…72 — Polícromo** (Lisbon palette): cobalt + yellow + green + manganese pattern tiles.

Every cobalt tile binds to one Framer Color variable (**Azul**, default `#1E4FA3`), so the whole set recolors from a single control. All 72 tiles also ship as SVG files and transparent PNGs at 1000px and 2000px — free, in this repo's releases.

## How it's built

Motifs are generated by code (a symmetry grammar: quarter tile → mirrored to full tile), never traced from historical panels — the designs are original, in the manner of the tradition. Generation scripts, QA renders (including 4×4 panel renders that prove the repeats), and the full spec live in this repo. See `AGENT_INSTRUCTIONS.md`.
