## 2. Design system

- **Cobalt:** `#1E4FA3` ("Azul"). Cobalt tiles are the blue motif only, on transparency — the white ground belongs to the user's page. Gallery and showcase render them on white `#FFFFFF`.
- **Color variable (required):** every cobalt fill in the set binds to a single Framer Color variable named **Azul**, default `#1E4FA3`, so a user recolors all 64 cobalt tiles from one control. Verify the variable survives inserting a tile into a fresh project; record the result in the PR.
- **Lisbon palette (Polícromo, static fills):** Azul `#1E4FA3`, Amarelo `#E3A008`, Verde `#3E7C4F`, Manganês `#7A4E7E`, on the same transparent ground.
- **Geometry:** one artboard, 1000×1000. Motifs are filled paths (the painted areas), built from the grammar in §3. Keep path counts modest and nodes clean — Framer's best practices ask for optimized, lightweight paths. No strokes for the painted motifs; if a design wants a line, draw it as a thin filled shape.
- **Consistency:** one visual hand across all 72 — same corner language, same band weights, same rosette construction. A tile from any group should look like family next to any other.

## 3. Motif grammar (how the tiles are designed)

Designs are **generated by code** from a quarter-tile grammar, in the manner of traditional padrão panels. Never trace or copy a historical panel or any existing set (DECISION_LOG D9).

**Padrão construction (the seamless rule):** design one quarter of the tile (500×500), then mirror it across both axes to complete the tile. The classic arrangement:

- a large motif centred on one corner of the quarter (rosette, eight-point star, beaded medallion) — at the panel level, four tiles' corners merge into one full medallion;
- a small motif on the opposite corner (quatrefoil, small rosette, star);
- a lace band along the diagonal linking them (circles, double circles, diamond strap);
- a small motif where the band crosses each edge midpoint — edge motifs are what make neighbouring tiles read as one cloth.

Because the quarter is mirrored, edge continuity holds by construction — but you still run the seam QA in §5; construction is a claim, renders are the evidence.

**Motif bank** (combine, vary scale/weight; each tile gets a Portuguese name from its dominant motif): Estrela (eight-point star), Roseta (rosette), Quadrifólio (quatrefoil), Cata-Vento (pinwheel), Renda (lace band), Losango (diamond), Concha (scallop), Coração (heart), Sol (sun), Onda (wave), Cruz (cross), Flor (flower), Pinha (pinecone), Folha (leaf), Espiral (spiral), Meia-Lua (half-moon), Trevo (trefoil), Leque (fan).

**Medalhão:** complete centred compositions — a medallion (rosette/star/quatrefoil) inside a ring or scalloped border, corner flourishes optional. Not required to panel.

**Polícromo:** padrão construction (§3) with the motif layers split across the four palette colours — cobalt structure, yellow/green/manganese accents, the way Lisbon panels layer colour.

## 4. Generation

- Write the generator as scripts in `scripts/` (Python + SVG output is fine). Every tile's SVG is a build artifact of a script run — no hand-drawn one-offs, so any tile can be regenerated and fixed in code.
- Naming: files `assets/svg/AZL-01.svg` … `AZL-72.svg`; the tile's Portuguese name lives in `TILES.md` (id, name, group, dominant motifs) and in the Framer item name (`AZL-01 Estrela`).
- Exports per tile: SVG; PNG at 1000px and 2000px, cobalt shapes on transparency (polychrome in palette). `assets/svg/`, `assets/png-1000/`, `assets/png-2000/`.

## 5. QA gates (all must pass before the Framer build)

Record results in `TILE_TEST.md`, per tile, like Porthole's MASK_TEST.md.

1. **Render test:** every tile rendered at 200px and 1000px; edges clean, no stray points, no self-intersections.
2. **Panel test (Padrão + Polícromo, 56 tiles):** render each tile in 2×2 and 4×4 panels on white. Check the seams: motifs must continue across boundaries with no jumps, and the merged corner medallions must close. Include a programmatic seam check (compare the tile's left edge profile against its right, top against bottom, in the raster) **and** eyeball the panel sheets.
3. **Contact sheets:** all 72 on white, one sheet per group; plus one sheet of 4×4 panels (a selection of 12 padrão tiles at panel scale is fine if all 56 panels are in `qa/panels/` individually).
4. **Variable test (after the Framer build):** insert three cobalt tiles into a fresh project, change Azul once, confirm all three recolor.

Fix failures in the generator, never by hand-editing an SVG.
